# Apple Kids category compliance (T10.7)

Checked against Apple's App Review Guidelines 1.3 (Kids Category) and 5.1.4 (Kids), plus Google Play's Families policy. Each row links to the evidence in the code.

| Requirement                                                       | Status     | Evidence                                                                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No third-party analytics or advertising                           | ✅         | The Cloudflare beacon only runs in web production builds and never inside the apps (`apps/player-web/src/lib/webAnalytics.ts`). Game events are counted first-party in the `plays` table. No ads SDKs.                                                                                                                       |
| No data sent to third parties except as needed for the service    | ✅         | Firebase Auth (sign-in) and our own API (Supabase Postgres). See `/privacy`.                                                                                                                                                                                                                                                 |
| Parental gate before external links, email, sharing and purchases | ✅         | One gate for everything that leaves the app. The native adapters' `share()` and `openUrl()` call `requestGrownUp()` (`platform/parentGate.ts`, tested), answered by `GrownUpGateHost` (`components/GrownUpLink.tsx`). The question is a multiplication written in words. Purchases (T12.3) must call `requestGrownUp()` too. |
| No links out of the app without the gate                          | ✅         | External links go through `GrownUpLink`, and `adapters.app.openUrl` is called only from it. Re-check whenever a new link is added: `git grep -n 'href="http\|openUrl(' apps/player-web/src`                                                                                                                                  |
| No behavioural advertising or tracking                            | ✅         | No IDFA or ATT prompt is needed. Nothing tracks across apps.                                                                                                                                                                                                                                                                 |
| Account deletion inside the app                                   | ✅         | Settings → Delete my account (T7.8), `DELETE /me`.                                                                                                                                                                                                                                                                           |
| Social features don't expose kids publicly                        | ✅         | Friends only, by code, with requests and block (T7.6). No search by name. Presence is off by default. Public profiles show screen name, avatar, level and stickers only.                                                                                                                                                     |
| User-generated content is moderated                               | ✅         | Screen names are filtered (`obscenity` plus a reserved list), 3 changes per 30 days, with an admin list of renames and reset (T6.7, T6.8).                                                                                                                                                                                   |
| Privacy policy reachable in the app and on the store              | ✅         | `/privacy`, linked from the drawer and the login page.                                                                                                                                                                                                                                                                       |
| Age band                                                          | 6–8        | See listing.md.                                                                                                                                                                                                                                                                                                              |
| Sign in with Apple offered if Google is (guideline 4.8)           | ✅ in code | Native Apple sign-in (T10.3). It needs the Apple Developer capability to be enabled.                                                                                                                                                                                                                                         |

**Before each submission:** run the grep above. Check the gate on a device: tap the email on `/parents`, cancel, then answer correctly. Confirm the store's privacy answers still match `/privacy`.
